# agtuned-vlm

Evaluation framework for vision-language models on agricultural image understanding.

## Prerequisites

```bash
uv sync
```

## Paper 1

**Paper:** [Vision-language models know more about agriculture than they show and rubric-grounded verifications close the gap](https://arxiv.org/abs/2609.09417)

### Experiments Pipeline

| Stage | Doc | What it does |
|---|---|---|
| 0a | [docs/stage0a_datasets.md](docs/stage0a_datasets.md) | Download & sample datasets from Project-AgML (HuggingFace) |
| 0b | [docs/stage0_data_generation.md](docs/stage0_data_generation.md) | (OPTIONAL) Fetch grounding sources (Wikipedia + web search) then synthesize classification JSONL from them |
| 1 | [docs/stage1_linear_probe.md](docs/stage1_linear_probe.md) | H1: test vision encoder feature separability across backbones |
| 2 | [docs/stage2_lower_upper_bounds.md](docs/stage2_lower_upper_bounds.md) | Lower (vision-only) vs. upper (description-augmented) classification bounds |
| 3 | [docs/stage3_cot.md](docs/stage3_cot.md) | Chain-of-thought: self-generated description vs. structured multi-step reasoning |
| 4 | [docs/stage4_verifier.md](docs/stage4_verifier.md) | Single-round verifier: K structured-criteria candidates ranked by a PPT tournament, argmax reported, vs. a full PPT-tournament baseline |

### Viewers

```bash
streamlit run app/classification_viewer.py -- --output_dir outputs/data_generation/
```

Browse Stage 0b's output: dataset/crop/class per record, the grounding sources fetched for it, and the synthesized description. Works right after Step 1 alone (before descriptions exist) too — see [app/README.md](app/README.md).

## Paper 2

**Paper:** TBA

### Experiments Pipeline

| Stage | Doc | What it does |
|---|---|---|
| 0 | [docs/stage0_judge_improvements.md](docs/stage0_judge_improvements.md) | LLM judge leniency (Phase 1), self-consistency (Phase 2), and template sensitivity (Phase 3, `hybrid` template) on the thinking-enabled classification checkpoint (generated by Stage 1) — judge thinking on by default; includes a human-QA review export for hand-checking judge verdicts |
| 1 | [docs/stage1_baseline_classification.md](docs/stage1_baseline_classification.md) | Baseline classification runs: the plain, thinking-enabled single-shot classification checkpoint (no rubric, no verifier) every later stage builds on |
| 2 | [docs/stage2_object_detection.md](docs/stage2_object_detection.md) | Baseline object detection runs (a Paper 1 leftover): builds a class-balanced 10-images/class manifest (`dataset/selected_images_detection_10.json`) from Project-AgML's detection-type datasets, then runs Detection-Baseline (direct box prediction, no reasoning) with IoU-based precision/recall/F1 + QC plots — the spatial-task analog of Stage 1. Rubric/verifier conditions deferred to Stage 4 |
| 3 | [docs/stage3_classification_verifier.md](docs/stage3_classification_verifier.md) | Classification verifier runs: `verifier-cot`'s new default (`--verifier_type simple`) — ONE trajectory per image (no K-candidate pool, no PPT tournament), graded against each rubric criterion independently on a 1-3 scale and summed/normalized to a `verifier_score` in [0, 1]; reports its point-biserial correlation with judged correctness, to test whether this cheaper signal is usable as a stopping/feedback gate (e.g. for Stage 5's ReAct agent) before adopting it there. `--from_ckpt` grades an existing Stage 1 checkpoint's trajectories directly instead of regenerating them |
| 4 | [docs/stage4_detection_verifier.md](docs/stage4_detection_verifier.md) | Detection verifier — the spatial-task analog of Stage 3, applied to object detection. Design not started yet (placeholder doc) |
| 5 | [docs/stage5_react_baseline.md](docs/stage5_react_baseline.md) | ReAct baseline: a tool-using agent (`read`/`glob`/`grep`/`write` + agml-agent's `retrieve`/`search_agml`) over the model's own native tool calling via vLLM — one checkpoint row per episode (resumable), a shared per-model trajectory log, and a Streamlit viewer (`app/react_baseline_viewer.py`); starts with a 3-task text-only smoke test, real heldout-image harness not built yet |

### Viewers

```bash
streamlit run app/react_baseline_viewer.py -- --output_dir outputs_final/react_baseline/
```

Browse Stage 5's ReAct baseline output — per-episode task/result/trajectory, filterable by `stop_reason`, with per-episode timing. See [docs/stage5_react_baseline.md](docs/stage5_react_baseline.md).
