# agtuned-vlm

Evaluation framework for vision-language models on agricultural image understanding.

## Prerequisites

```bash
uv sync
```

## Experiments Pipeline

| Stage | Doc | What it does |
|---|---|---|

## Dataset splits

Manifest files recording exactly which images are in each split (regenerated by running the scripts below, not static files for the full-scale runs):

| Split | Manifest | Generated by |
|---|---|---|
| Zero-shot baseline pool (classification) | `dataset/selected_images.json` | `scripts/agml_hf/download_and_sample.py` |
| Zero-shot baseline pool (detection) | `dataset/selected_images_detection.json` | `scripts/agml_hf/download_and_sample_detection.py` |
| Held-out skill-memory/DPO pool — disease/pest | `dataset/heldout_selected_images.json` | `scripts/download_heldout_digitalgreen.py` |
| Held-out skill-memory/DPO pool — quality | `dataset/heldout_quality_selected_images.json` | `scripts/download_heldout_quality.py` |
| Held-out skill-memory/DPO pool — species | `dataset/heldout_species_selected_images.json` | `scripts/download_heldout_species.py` |
| Held-out skill-memory/DPO pool — detection | `dataset/detection_heldout_selected_images.json` | `scripts/download_heldout_detection.py` |

Each held-out manifest's rows carry a `split` field (`lessons` or `eval`) marking which half of the 80/20 split that row belongs to; see [docs/stage3_context_memory.md](docs/stage3_context_memory.md) / [docs/stage4_detection_context_memory.md](docs/stage4_detection_context_memory.md) for how that split is used.
